# Auralis Vision

Auralis aims to be the premier cross-platform music library manager, offering seamless organization, metadata enhancement, and audio analysis.

## Core Values

1.  **Cross-Platform First:** Support Windows, macOS, and Linux natively.
2.  **Flexible UI:** Provide multiple UI backends (PyQt6, wxPython) to suit user preference and system integration.
3.  **Intelligent Organization:** Leverage audio content analysis (fingerprinting, language detection) for superior organization.
4.  **Extensible:** Modular architecture allowing easy addition of new metadata sources and organization rules.

## Long-Term Goals

-   **Full wxPython Support:** Complete implementation of the wxPython backend.
-   **Cloud Integration:** Sync library metadata across devices.
-   **Advanced Audio Analysis:** BPM detection, key detection, and mood classification.
-   **Plugin System:** Allow third-party developers to extend functionality.
